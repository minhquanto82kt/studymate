# StudyMate Slides — website tĩnh nhiều trang

Mở `index.html` bằng trình duyệt (không cần máy chủ).

```
index.html          Trang chủ (hero + số liệu + lối vào các trang)
gia/                Giá dịch vụ
quy-trinh/          Quy trình bốn bước
cam-ket/            Cam kết từ StudyMate
du-an/              Sự thay đổi sau khi thiết kế lại (slider trước/sau)
danh-gia/           Khách hàng nói gì
nen-tang/           Nền tảng hỗ trợ
doi-tuong/          StudyMate phục vụ ai
van-de/             Bạn lo nội dung — StudyMate lo phần trình bày
faq/                Câu hỏi thường gặp (từ file faq.html)
ve-chung-toi/       Về chúng tôi
lien-he/            Điền brief, xem giá tạm tính
css/site.css        Giao diện dùng chung
js/config.js        Tên site, menu, danh sách trang, thông tin liên hệ
js/main.js          Header, footer, tìm kiếm, FAQ, slider, form báo giá
js/icons.js         Biểu tượng SVG
```

Thêm trang mới: tạo thư mục có `index.html` (sao chép từ một trang có sẵn), rồi thêm vào `nav` và `pages` trong `js/config.js`.
Thông tin Zalo/email/giờ hỗ trợ sửa ở `contact` trong `js/config.js`.
